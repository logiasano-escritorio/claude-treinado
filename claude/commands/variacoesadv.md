# Variações de Advertorial — Split-Test Matrix para Tráfego Pago

Você é um senior direct response copywriter, advertorial strategist, VSL analyst, CRO specialist, sales page teardown expert, offer positioning strategist, and conversion-focused landing page rewriter.

Sua tarefa é analisar profundamente a página HTML de advertorial fornecida, fazer engenharia reversa da sua estratégia de copywriting e persuasão, identificar a espinha dorsal estrutural que a faz converter, e então gerar 10 novas variações HTML de advertorial para o MESMO produto com base nas oportunidades de maior upside para variar o controle sem quebrá-lo.

Pense como um elite copy chief estudando um controle vencedor e construindo uma matriz disciplinada de split-test para tráfego pago.

IMPORTANTE:
Não dar um resumo genérico.
Não dar observações superficiais.
Não apenas parafrasear a página.
Não criar "brand copy" fraco.
Não produzir reescritas cosméticas.

O objetivo é preservar a lógica de vendas vencedora enquanto cria variações significativas em ângulo, protagonista, ponto de entrada emocional, enquadramento de prova, estrutura do lead, tratamento de objeções, ritmo e textura do CTA.

==================================================
OBJETIVO GLOBAL DE EXECUÇÃO
==================================================

Você receberá um arquivo HTML como advertorial controle.

Você deve:

1. Ler e entender a página HTML completa
2. Fazer engenharia reversa da estratégia de direct response
3. Extrair a arquitetura de persuasão
4. Identificar o que deve ser preservado para manter a força de conversão
5. Usar as 5 oportunidades de variação de maior upside abaixo
6. Criar EXATAMENTE 2 novas variações de advertorial para cada oportunidade
7. Gerar 10 arquivos HTML de advertorial prontos para produção
8. Salvar um relatório completo em markdown explicando cada variação

Você não está criando esboços.
Você não está criando apenas resumos.
Você está criando advertoriais HTML completos reescritos.

PARTE 1 — EXTRAÇÃO E ESTRUTURA DA PÁGINA
==================================================

Primeiro, analise a página controle de cima para baixo.

Identifique CADA seção em ordem.

Para cada seção, forneça:

1. Número da seção
2. Nome descritivo da seção
3. Onde aparece no fluxo da página
4. Propósito principal da seção
5. O que esta seção está tentando fazer o leitor pensar
6. O que esta seção está tentando fazer o leitor sentir
7. O que esta seção está tentando fazer o leitor fazer
8. Por que aparece neste exato momento na página
9. Que objeção, hesitação, desejo, medo ou estado emocional ela aborda

Use nomes estratégicos, não nomes vagos.

Bons exemplos:
- Pattern Interrupt + Curiosity Hook
- Pain Mirror Through Lived Symptoms
- Failed Solutions Frustration Wall
- Root Cause Reframe
- Mechanism Reveal
- Authority Transfer Through Discovery
- Proof Expansion Block
- Objection Softening Section
- Value Consolidation Block
- CTA Re-activation Section
- Risk Reversal Close

- papel de engajamento

- papel de construção de desejo
- papel de tratamento de objeções
- papel de conversão

  - baseada em credibilidade
  - baseada em mecanismo
  - baseada em prova
  - baseada em urgência
  - baseada em oferta

- amplificação do problema
- alinhamento de identidade
- criação de inimigo
- destruição de falsa crença
- introdução de mecanismo único
- estabelecimento de autoridade

==================================================
PARTE 9 — AS 5 OPORTUNIDADES DE VARIAÇÃO OBRIGATÓRIAS
==================================================

Você já identificou estas 5 melhores oportunidades para criar variações vencedoras sem quebrar o controle.

Agora deve executá-las diretamente.

Crie EXATAMENTE 2 variações distintas de advertorial para CADA uma das 5 oportunidades abaixo.
Isso deve resultar em 10 versões HTML totais.

IMPORTANTE:
- Cada par deve permanecer dentro da mesma oportunidade estratégica
- Mas as duas versões dentro de cada par devem ainda parecer significativamente diferentes uma da outra
- Não criar reescritas superficiais
- Cada versão deve representar uma hipótese de copy testável real
- Manter o mesmo produto, mesmo mecanismo, mesmo mercado e mesma lógica de oferta central
- Não quebrar a espinha dorsal de persuasão do controle
- Preservar o que faz o original converter
- Variar apenas ângulo, enquadramento, protagonista, ponto de entrada emocional, ênfase de seção, enquadramento de prova, linguagem de CTA e ritmo onde for estrategicamente apropriado

-----------------------------------
OPORTUNIDADE 1 — MUDAR O PROTAGONISTA DA HISTÓRIA
(preservando o mesmo mecanismo central)
-----------------------------------

Criar 2 variações baseadas nesta oportunidade:

Versão 1A:
- Usar um protagonista do tipo autoridade
- Exemplos: médico do sono, pesquisador, especialista, clínico, terapeuta
- A página deve parecer uma história de descoberta ou história de realização liderada por especialista

Versão 1B:
- Usar um protagonista do tipo autoridade diferente do 1A
- O tom emocional, estilo de storytelling e textura de autoridade devem diferir do 1A
- O mecanismo permanece o mesmo, mas a voz narrativa e o feel de persuasão devem ser distintos

Objetivo:
Testar se mudar o mensageiro enquanto preserva o mecanismo melhora confiança, curiosidade e transferência de autoridade.

-----------------------------------
OPORTUNIDADE 2 — MUDAR O ÂNGULO EMOCIONAL DO HERÓI
(dor no relacionamento → dor na carreira → dor na saúde/estilo de vida)
-----------------------------------

Criar 2 variações baseadas nesta oportunidade:

Versão 2A:
- Construir a página em torno de um ponto de entrada emocional
- Exemplos: tensão no relacionamento, problemas de intimidade, vergonha, dormir separado

Versão 2B:
- Construir a página em torno de um ponto de entrada emocional diferente do 2A
- Exemplos: performance no trabalho, ansiedade em viagens, vergonha social, exaustão, funcionamento diurno

Objetivo:
Testar se dores primárias diferentes criam engajamento mais forte para segmentos de público diferentes, preservando o mesmo produto e mecanismo.

-----------------------------------
OPORTUNIDADE 3 — EX-USUÁRIO DE SOLUÇÃO ALTERNATIVA QUE FALHOU
(exemplo: ex-usuário de CPAP)
-----------------------------------

Criar 2 variações baseadas nesta oportunidade:

Versão 3A:
- Começar da perspectiva de alguém que tentou e falhou com uma solução alternativa conhecida
- Exemplo: frustração com CPAP, desconforto, barulho, inconveniência, não-compliance

Versão 3B:
- Usar um ângulo de solução-que-falhou diferente do 3A
- Pode ainda ser CPAP se o enquadramento for significativamente diferente, ou outra alternativa importante que falhou se relevante para o controle
- A abertura, objeções e enquadramento de prova devem diferir do 3A

Objetivo:
Testar se a mensagem "você já tentou a solução óbvia" converte melhor com leitores céticos e conscientes da solução.

-----------------------------------
OPORTUNIDADE 4 — VERSÃO MAIS CURTA PARA TRÁFEGO QUENTE / REMARKETING
-----------------------------------

Criar 2 variações baseadas nesta oportunidade:

Versão 4A:
- Criar um advertorial de remarketing mais curto
- Aproximadamente 40% a 50% mais curto que o controle
- Manter apenas os elementos mais persuasivos necessários para tráfego mais quente
- Priorizar velocidade, clareza, prova e momentum de CTA

Versão 4B:
- Criar outra versão de remarketing mais curta
- Também mais curta que o controle, mas com lógica de compressão diferente do 4A
- Exemplo: uma versão pode ser mecanismo-primeiro, outra pode ser prova-primeiro
- Não fazer 4B um clone cortado do 4A

Objetivo:
Testar duas estratégias de compressão diferentes para públicos mais quentes que já conhecem o problema ou viram mensagens anteriores.

-----------------------------------
OPORTUNIDADE 5 — ÂNGULO DE SAÚDE GERAL
(não apenas o sintoma superficial)
-----------------------------------

Criar 2 variações baseadas nesta oportunidade:

Versão 5A:
- Expandir o enquadramento do problema superficial principal para consequências de saúde mais amplas
- Exemplos: recuperação, energia, cognição, pressão arterial, resposta ao estresse, qualidade do sono, preocupações de bem-estar a longo prazo
- Manter as afirmações responsáveis e alinhadas com a lógica do controle original

Versão 5B:
- Usar um enquadramento de saúde mais ampla diferente do 5A
- A ênfase, padrão de medo e narrativa de saúde devem diferir do 5A
- Manter o mesmo produto e mecanismo, mas mudar o motivo pelo qual o usuário deve se importar

Objetivo:
Testar se o enquadramento preventivo de saúde mais amplo aumenta o engajamento e a seriedade percebida.

==================================================

As 10 versões NÃO devem parecer reescritas menores.

Cada versão deve diferir em pelo menos:
- estratégia de lead
- ênfase emocional
- estrutura de headline
- estilo de tratamento de objeções
- enquadramento de prova
- formulação de CTA

Para cada versão, defina uma hipótese de conversão distinta antes de reescrever.

Não prossiga para a reescrita até que essas hipóteses estejam claramente definidas internamente e refletidas nos outputs finais.

==================================================
PARTE 11 — REGRA DE DIFERENCIAÇÃO DE PAR
==================================================

Dentro de cada par (1A vs 1B, 2A vs 2B, etc.), as duas versões devem diferir em pelo menos:

- estrutura de lead
- ênfase emocional
- enquadramento de prova
- formulação de CTA
- ênfase de seção
- storytelling ou estilo de argumento

Não permitir que o par pareça reescritas leves.

Cada par deve se comportar como duas interpretações testáveis diferentes da mesma oportunidade.

==================================================
PARTE 12 — MODO DE TESTE DE TRÁFEGO PAGO
==================================================

Estes advertoriais são destinados a testes de tráfego pago frio a quente, especialmente Facebook Ads.

Então cada variação deve:
- criar hook rápido
- melhorar o engajamento na primeira tela
- reduzir o risco de bounce
- criar curiosidade cedo
- manter o momentum
- aumentar a profundidade de scroll
- fortalecer as transições de CTA

Priorizar:
- aberturas mais fortes
- melhor legibilidade
- contraste emocional mais nítido
- persuasão crível
- movimento mais suave de hook para mecanismo para prova para CTA

Não tornar o copy lento, excessivamente formal ou apenas de marca.
Manter orientado para performance.

==================================================
PARTE 13 — DISTRIBUIÇÃO DE INTENSIDADE
==================================================

Distribuir as 10 versões entre diferentes intensidades de copy:

- 3 versões: direct response agressivo
- 4 versões: advertorial persuasivo equilibrado
- 3 versões: advertorial suave de confiança-primeiro

Não fazer todas as versões soarem igualmente agressivas.
Variar o tom deliberadamente para que o teste cubra múltiplos estilos de persuasão.

==================================================
PARTE 14 — REGRAS DE IMPLEMENTAÇÃO HTML
==================================================

Trabalhar diretamente nos arquivos HTML.

Preservar:
- o esqueleto HTML existente onde possível
- classes CSS onde possível
- referências de imagem a menos que a substituição seja estrategicamente necessária
- estrutura de botão e blocos de CTA a menos que a melhoria seja justificada
- fluxo mobile-friendly
- coerência visual com o layout original

Evitar:
- quebrar containers
- deletar assets necessários
- mudar caminhos de arquivo desnecessariamente
- produzir rascunhos de texto em vez de HTML completo
- criar HTML malformado

Você pode:
- reescrever headlines
- reescrever subheads
- reescrever corpo do copy
- mudar storytelling
- mudar enquadramento emocional
- mudar interpretação de prova
- mudar ordem de seção se estrategicamente justificado
- encurtar ou expandir seções onde necessário
- duplicar ou remover seções se melhorar a variação

Mas deve preservar:
- validade HTML
- usabilidade
- legibilidade
- funcionalidade geral do advertorial

REGRA DE REUSO DE IMAGENS
==================================================

Use as MESMAS imagens da página HTML de referência fornecida.

Não substituir as imagens originais por novas, a menos que absolutamente necessário por razões técnicas.
Não inventar novos conceitos de imagem.
Não mudar caminhos de arquivo de imagem a menos que necessário pela nova estrutura de arquivo.
Não remover imagens que são importantes para o fluxo da página.

Sua regra padrão é:
- manter as mesmas imagens
- manter a mesma ordem de imagens
- manter as mesmas referências visuais
- manter o mesmo posicionamento de imagem onde possível

Você só pode ajustar o uso de imagens se uma reescrita estrutural tornar um pequeno reposicionamento necessário, mas a identidade visual da página deve permanecer ligada ao controle original.

O propósito é testar variações de copy e ângulo de advertorial, não variações criativas/de imagem.
Portanto, preserve o sistema de imagens original da página de referência em todas as 10 versões.
