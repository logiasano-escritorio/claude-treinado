## SALVAR ARQUIVO

Se o usuário forneceu um arquivo como input (ex: `produto.html`, `pagina.md`, `copy.txt`):
- Salve o resultado em um **novo arquivo** com `-es` adicionado ao nome, **sem sobrescrever o original**
- Exemplos:
  - `produto.html` → `produto-es.html`
  - `pagina-relivia.md` → `pagina-relivia-es.md`
  - `copy.txt` → `copy-es.txt`
- Se já existir um `produto-es.html`, crie `produto-es-2.html`, `produto-es-3.html`, etc.
- Salve no mesmo diretório do arquivo original.

Se o usuário colou o conteúdo diretamente (sem arquivo), apenas exiba o resultado na conversa.
