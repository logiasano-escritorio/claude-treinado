## Paleta oficial Relívia

```css
--blue:      #2E2BFF   /* botões, preços, badges, CTAs — cor principal */
--blue-dark: #1B17FF   /* hover, wave fill */
--white:     #ffffff
--gray:      #F5F6F8   /* seções alternadas, cards */
--text:      #111111   /* body, títulos, footer bg */
--muted:     #666666   /* texto secundário */
--stars:     #ffcc00   /* estrelas de avaliação */
```

**Atenção:** A cor primária da Relívia é AZUL (#2E2BFF), não verde. O comando `/adaptarpagina` usa verde (#00C853) mas esse é para outras marcas — a Relívia usa azul conforme `/relivia-pagina.md`.
