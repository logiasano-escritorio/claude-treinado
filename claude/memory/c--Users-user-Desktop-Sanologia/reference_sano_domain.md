**Domínio Sano:** `sanobrasil.com`

**Como aplicar:** Sempre que precisar montar URL de produção de qualquer advertorial ou página Sano (B12, GlowUp, StrongBones, futuros), usar `https://sanobrasil.com/...`. **Nunca** assumir `sano-v2.vercel.app` ou perguntar de novo.

**Checkout (separado, não Sano):** `https://pagamento.reliviaonline.com/sano-{sku}` — fica em `reliviaonline.com` mesmo.

**Projeto Vercel:** `sano-v2` (interno; o domínio público apontado é `sanobrasil.com`).
