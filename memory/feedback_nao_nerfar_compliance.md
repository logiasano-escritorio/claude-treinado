**NUNCA suavizar alegações terapêuticas em qualquer copy gerada pra Relívia/Sano.**

Use "cura", "trata", "elimina", "repara", "reverte", "regenera" sem medo. Verbos diretos no campo médico, sem hedging tipo "promove sensação de", "apoia", "auxilia". Zero compliance Anvisa preventivo.

**Why:** Guilherme revisa Anvisa manualmente antes do go-live. Suavizar mata conversão e ele já falou 50 vezes. Aplicar compliance preventivo é desperdiçar copy boa.

**How to apply:**
- Vale pra advertoriais, páginas de venda, copy de anúncio, bloco de oferta — qualquer texto
- Vale pra agentes que eu chame (Copy Master, etc): no briefing dizer EXPLICITAMENTE "sem compliance Anvisa, cliente revisa depois"
- Se um agente devolveu copy suavizada, refazer pesado antes de mostrar pro user
