Docs de pesquisa de público pra copy ficam no vault Obsidian em `SANOLOGIA OBSIDIAN/Research/` — **1 doc mestre por AVATAR** (não por produto), banco de gênero separado (masc-only / fem-only) pra nunca vazar frase do gênero errado [[feedback_criativo_nao_pode_mentir_destino]]. Ex: `Research/Tonico-Supremo-Masculino.md`.

**Estrutura v2 (9 seções) — é arsenal de munição, não resumo:**
1. Avatar (quem, momento-gatilho, nível de consciência dominante)
2. Diálogo Interno (a conversa das 2h da manhã — vira lead de advertorial)
3. Dores & Medos taggeadas por nível de consciência Schwartz (`[inconsciente]`/`[consc-problema]`/`[consc-solução]`/`[consc-produto]`)
4. Desejos & Sonhos
5. Inimigo Comum (o vilão a demonizar — mecanismo do "não é sua culpa")
6. Objeções & Ceticismo
7. **Swipe File — fichas ricas por frase-ouro:** verbatim + fonte/link + engajamento + emoção + nível + `usar em: hook/lead/agitação/objeção/prova/CTA` + sugestão PT-BR. Verbatim EN → adaptar sem suavizar alegação [[feedback_nao_suavizar_alegacoes]]
8. Ângulos de Copy: cada ângulo = dor→inimigo→big idea→mecanismo único→prova→destino. É o briefing pronto pro `/copy-anuncio`, `/gerar-advertorial` e agentes Copy Master
9. Log de Pesquisa (data/fonte/query/achados/raw) + próximas queries sugeridas

Cada doc começa com **Seção 0 — Ficha do Produto** (composição REAL da página, "não citar o que não tem") pra copy nunca mentir ingrediente. Ex Tônico: café verde/Baicapil/Beauplex; NÃO tem saw palmetto/minoxidil.

**Fluxo:** pesquisa (`/last30days` com X via [[reference_last30days_skill]] + Reddit) alimenta as seções → doc cresce a cada rodada → Seção 8 vira input direto do pipeline de copy. Por que verbatim importa: "castração química" vende, "efeitos colaterais" não — usar as palavras exatas do cliente.

**Docs existentes:** `Research/Tonico-Supremo-Masculino.md` (calvície, inimigo=finasterida/PFS) e `Research/Tonico-Supremo-Feminino.md` (menopausa, estrogênio↓→DHT). `Research/FungZero.md` (fungo unha/onicomicose, avatar NEUTRO; produto=blend 7 óleos tea tree; 5 ângulos: remédio 30-40%+fígado / tea tree sozinho não resolve vs blend / vergonha-esconder / medicina desistiu / urgência-destruição). **Regra confirmada 2026: SEMPRE montar VÁRIOS ângulos por produto (não escolher 1) — o doc é arsenal completo.**
